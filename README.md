# API REST com Spring Boot e Java

Construi uma API REST, utilizando as ferramentas que o Spring Boot oferece, junto com a linguagem Java. O foco desse projeto foi a implementação de um CRUD (Create, Read, Update e Delete) para gerenciar produtos de uma pizzaria, este projeto foi necessário para a matéria de Programação Orientada a Objetos, no curso de Ciência da Computação da UNIP Marquês.

Para este projeto foram utilizadas as ferramentas:

<ul>
  <li>Spring Web</li>
  <li>Spring Boot DevTools</li>
  <li>SPring Data JPA</li>
  <li>H2 Database</li>
  <li>Lombok</li>
</ul>
